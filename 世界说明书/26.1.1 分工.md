# 分工

这周每人写好自己的部分，转成.md格式，发在github上面文件夹/世界说明书/markdown/

我们采用latex自动化排版，所以需要遵守文件规范

## 文件规范：

1. md命名规范"1 世界总体设计.md"
2. 图片命名规范"1 building_2.jpg""1 structure.png""1 建筑"，其中1表示是说明书第一章的，格式只能用.jpg或.png，如果要别的格式需要转码。中英文命名均可
3. 文件夹结构是“/世界说明书/markdown/"和"/世界说明书/image/"。文档放在/世界说明书/markdown/，图片放在/世界说明书/image/
4. 在每个文档中有需要插入的插入图片，单独一行，写图片名字，必须与文件名一模一样，如"3 human_group.jpg"

## 格式规范：

1. 文件格式列举最多1层，出现的大段粗体需要去除
2. 标题用"# 1 世界总体设计"，一级标题1.2用"## 1.2 能源"，二级标题1.2.4用"### 1.2.4 发电规划"（我会发一个协助排版的AI提示词来完成这一部分）
3. 自然段不要过长，可以手动分自然段
4. 完整效果参考我发在群里的书《你不知道的进化论发展史》

## 内容要求：

1. 图文对应（每出现一张图，正文部分要有对应的讲解）
2. 要有涉及未来科技的展望内容。可以再加一个章节如4.7
3. 所有参考他人的资料都要有出处（来自网络的，标注网址），网址就放在引用出正后方。网址必须可访问
4. **语言风格：**(1)重点突出，可以自由发挥，觉得没必要写直接删；(2)结合我们世界的理念“在高度发达的社会，人类可以脱离工具性而存在时会怎样发展？”；(3)有连接性的话语，介绍口吻，机味不要重

## 不需要满足的要求：

以下都交给latex自动化来实现，无需手写：全书目录、字体字号、居中、插入图片
